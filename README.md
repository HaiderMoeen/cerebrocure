# Cerebrocure — AI-Powered Neurological Diagnostics & Clinical Platform

![Cerebrocure Banner](https://raw.githubusercontent.com/HaiderMoeen/cerebrocure/main/public/logo.png)

**Cerebrocure Technologies Pvt Ltd** is an advanced healthcare technology enterprise specializing in artificial intelligence for precision neurological imaging, early stroke detection, automated scan triage, and clinical decision support.

## 🛠️ Technology Stack

- **Core Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling & UI Design**: Custom Dark Glassmorphic Design System built with [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Routing**: Lightweight Hash-based Client Router (`useHashRoute`)

## 🚀 Getting Started Locally

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v16+ recommended) installed on your machine.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/HaiderMoeen/cerebrocure.git
   cd cerebrocure
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser to view the application.

4. **Build for Production**:
   ```bash
   npm run build
   ```
